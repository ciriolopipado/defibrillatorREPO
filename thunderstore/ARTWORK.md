# Artwork

`cover.png` is original AI-generated promotional artwork created for Industrial Defibrillator using OpenAI image generation.
It depicts an orange industrial defibrillator, charged paddles, a revived original robot character and electrical aftereffects.
It is an illustration, not an in-game screenshot or a representation of the exact procedural model.

The English title and tagline match the project convention:

- INDUSTRIAL DEFIBRILLATOR
- REVIVE. RECHARGE. REPEAT.

The source cover is preserved at its generated resolution. `icon.png` is its opaque 256 × 256 PNG adaptation for Thunderstore.
Run `bash scripts/create-icon.sh` with ImageMagick installed to regenerate the icon without changing the cover.
Create or revise the artwork using the image-generation tool; the helper performs only packaging-size conversion.
